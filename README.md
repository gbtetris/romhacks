# romhacks
Root repo of romhacks (stable and dev) for Game Boy Tetris.

## Please Note
No copyrighted ROM versions of Tetris are included in the repository.

To apply any patch, you must provide your own legally obtained copy of the Game Boy Tetris (v1.1) ROM.
Do not upload or distribute ROM files here. Only patch files (IPS/BPS), tools, and documentation are permitted.
